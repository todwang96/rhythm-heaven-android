# Screenshots

This repository intentionally does not commit screenshots or artwork from the game: they are
copyrighted material and must not be redistributed.

If you want to show the port, please upload screenshots of **your own setup** to the release assets
(or a personal page) and link them from the README — the same approach as other bring-your-own-files
ports. The launcher background and app icon in this repository are placeholder artwork drawn for
this project; replace them with your own images if you like:

```
android/app/res/drawable-nodpi/launcher_bg.webp     # 1920x1080 launcher background
android/app/res/mipmap-*/ic_launcher.png            # app icons
android/app/res/mipmap-*/ic_launcher_foreground.png # adaptive icon foreground
```
